# 邻桥快传 1.0.2.1 验证报告

验证日期：2026-09-21。环境：Windows 11 x64（10.0.26200），Python 3.8.10 x64 / Tk 8.6.9 / PyInstaller 5.13.2 / Inno Setup 6。

## 交付内容

`dist` 内包含四个独立文件：`邻桥快传-发送端.exe`、`邻桥快传-接收端.exe`、`邻桥快传-发送端-安装包.exe`、`邻桥快传-接收端-安装包.exe`。Windows 文件版本、产品版本均为 **1.0.2.1**；校验值见 `dist/SHA256SUMS.txt`。

## 代码审查与回归

通读并交叉检查了全部应用源码、两端入口、打包定义、构建/验证脚本；保持 GUI、服务、协议、发现、路径、配置、日志分层。新增 `connection_memory.py` 与 `lan_scan.py` 承担独立逻辑。

Python 3.8.10 全套 **132 项 unittest 通过**；`src/tests/scripts` 的 Ruff F 类检查通过。最终打包验证脚本调整后另复跑 6 项打包测试通过。

覆盖通信握手、正确/错误访问码、恶意控制帧、路径越界与 Windows 保留名称、源文件变化、重名不覆盖、接收短写、取消与断连、磁盘/日志失败、接收服务重启、界面忙状态、过期/损坏历史、扫描取消/超时/掩码、最小窗口布局。日志另外使用 **4 个进程并发写入 96 条记录并强制轮换**，验证单表头与完整记录。

本次修复了多开日志竞争、扫描弹窗底部按钮被挤出、历史地址未恢复端口、同 IP 不同端口标签冲突、异常大整数时间戳导致启动失败等问题。

## 最终二进制验收

1. 四件产物检查 PE、版本和中文名称；便携版检查内置 Python 3.8 / Tcl / Tk，可脱离系统 Python 运行。
2. 两个便携 EXE 均成功启动并退出；两个安装包均完成静默安装、安装后启动与卸载。安装后的 EXE 与便携版 SHA-256 一致。测试安装使用专用 AppId、临时目录及 `/NOICONS`，测试卸载项已清理。
3. 实际启动最终接收端 EXE，服务级脚本向其成功传输 **68 个文件**：包含 12 MiB 二进制、中文嵌套路径、空文件、重名文件、24 次并发任务（4 个并发工作线程）及 40 次连续任务。逐一核对 SHA-256，无遗留 `.part`。
4. 实际操作最终发送端 EXE：自动扫描 → 双击接收端 → 自动填写 IP / 非默认端口 → 显示通信正常 → 选择文件夹 → 发送 3 个文件；随后从下拉菜单改选回环地址，再发送 1 个独立文件。**4 个 GUI 任务全部成功**，接收端累计显示 **72 完成 / 0 失败**，文件校验一致。
5. 发送成功后关闭并重新打开同一个发送端 EXE，检查保存的 `127.0.0.1:54567` 恢复，启动扫描保持该地址。该地址不同于首次默认填入的本机局域网 IP，端口也不同于默认端口。
